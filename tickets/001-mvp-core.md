## タスク：フレーム合成アプリ MVP の実装一式

- プロジェクト：フレーム合成アプリ（FrameBezelApp）
- 起票日：2026-11-11
- 仕様の参照：~/workspace/screenshot-frame-mac/spec.md（必ず全文を読むこと）
- プロジェクト規約：このプロジェクトの CLAUDE.md

### 背景
パイロットとして、AI協同開発体制の実装ループを一周させる。仕様は確定済み。個人用の macOS アプリで、配布はしない。

### やること
仕様 §5（機能仕様）と §9（開発ステップ 2〜5 相当）を実装する：
1. ベゼル定義モデルと JSON 入出力（仕様 §7 の形式）
2. ベゼル PNG の画面領域 自動検出（アルファ走査、外接矩形＋角丸推定）と JSON キャッシュ
3. ベゼル管理（Application Support への保存、追加・削除・名前変更、初回起動時の同梱分コピー）
4. 合成処理（背景 → スクショを画面領域に角丸クリップ → ベゼルを重ねる。背景は単色 / グラデーション / 透明、余白パラメータ対応）
5. SwiftUI の単一ウィンドウ UI（プレビュー、ドラッグ＆ドロップ / ファイル選択 / ペースト入力、設定パネル、PNG 書き出し）
6. プリセットの保存・呼び出し（名前付きでベゼル＋背景＋余白の組み合わせ）
7. README.md に、オーナーが Xcode でプロジェクトを作成しこのソースを取り込む手順を書く

## 結果（実装役が記入）

- 状態：実装完了（**未ビルド**。Linux 環境のため Xcode でのビルド・動作確認は一切できていない）
- やったこと：
  - Bezel モデル＋JSON 入出力（仕様 §7 の形式）
  - BezelDetector：縁からの塗りつぶしで「ベゼル外側の透明」を除外し、残った透明部の外接矩形を画面領域に。角丸は4隅の対角線上の最初の画面ピクセルまでの距離 k から r = k/(1−1/√2) で推定（4隅平均）
  - BezelLibrary：一覧・追加（コピー＋検出＋JSON、検出失敗時はコピーを消す）・削除・名前変更・更新、初回起動時の同梱分コピー（マーカーファイルで1回きり）

  - SwiftUI 単一ウィンドウ：プレビュー（D&D・ペースト）、ファイル選択、ベゼルサムネイル一覧、背景/余白/フィット、プリセット、PNG書き出し（前回フォルダ記憶、`{元名}_{機種名}.png` 提案）、ベゼル追加後の確認シート（赤枠オーバーレイ＋数値編集）
