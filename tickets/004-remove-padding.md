# タスク票 004

## タスク：余白（ベゼル外側のマージン）の廃止

- プロジェクト：フレーム合成アプリ（FrameBezelApp）
- 起票日：2026-11-11
- 仕様の参照：~/workspace/screenshot-frame-mac/spec.md §5.3・§5.5（2026-11-11 オーナー決定で更新済み）
- プロジェクト規約：このプロジェクトの CLAUDE.md
- 前提：チケット 001〜003 の実装が完了していること

### 背景
オーナー決定（2026-11-11）：
- 「余白」はベゼルのさらに外側に付ける余白の認識で合っている。そして、それは付けない（不要）
- プリセットに切り抜き調整（位置・拡大率）や回転状態は含めない（現状維持で確定。この件はコード変更なし）

### やること
1. 余白パラメータを廃止する
   - 合成の出力キャンバスは、ベゼル画像のサイズそのものにする（外側にマージンを足さない）
   - UI から余白の設定項目を外す
   - 背景（単色 / グラデーション / 透明）は、ベゼル画像の透明部分（デバイス輪郭の外側など）に現れるものとして残す
2. プリセットの保存内容から余白を外す（既存の presets.json に余白が含まれている場合は、読み込み時に無視して壊れないようにする）
3. 仕様 §5.5 の例（X投稿用など）が余白前提になっていないか確認し、なっていれば結果欄で指摘する

### 完了条件
- 上記 1・2 が実装されている
- ビルド成功は主張しない（この環境ではビルド不可）

### 制約・禁止事項
- CLAUDE.md の禁止事項に従う
- 仕様にない判断が必要になったら、結果欄に「要確認」として残す

### 成果物の置き場
- コード：このプロジェクトの Sources/ 配下
- 作業ログ：このファイルの「結果」欄
